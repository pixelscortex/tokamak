# Tokamak

## Agent skills

### Issue tracker

Issues live in Linear, team TKM, through the Linear MCP tools (GitHub holds code and PRs only). See `docs/agents/issue-tracker.md`.

### Design sync

Paper and the app stay in sync. Every change to what a screen looks like, in the same piece of work: (1) updates the plugin's `design/<plugin>.md`, (2) updates its `App 1:1` page in Paper so it looks the same as the app, and (3) checks the "If you change X, check Y" notes of every plugin listed as affected. Review checks all three. See `design/README.md`.

The owner's Paper pages (Chat, Plugins · coding, notes, System · rules, moodboard) are not edited; the `App 1:1` pages are kept by whoever changes the UI.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
