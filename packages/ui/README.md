# @tokamak/ui

Shared Solid 2 primitives and Tailwind tokens for Tokamak.

- `@tokamak/ui`: the primitives (Button, Menu, Dialog, Select, Row and the
  rest). Each source file starts with a comment that shows how to use it.
- `@tokamak/ui/theme.css`: the tokens (colours, type sizes, radii) as a
  Tailwind `@theme`.
- `@tokamak/ui/kit`: a page that draws every primitive in every state.
- `@tokamak/ui/lint`: the lint rules that keep plugins on the primitives.
