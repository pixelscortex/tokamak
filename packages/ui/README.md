# @tokamak/ui

Shared Solid 2 primitives and Tailwind tokens for Tokamak.

`Button` has three sizes: `sm` (24 px), `md` (32 px, default), and `lg`
(48 px). Use `sm` for compact actions in dense rows and dialogs. All sizes
support every variant and accept text, an icon with text, or an icon alone.
Icon-only buttons are square and need a `label` for their accessible name.
