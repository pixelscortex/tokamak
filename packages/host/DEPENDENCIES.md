# Plugin host dependencies

The new direct third-party crates are `llrt_abort`, `llrt_buffer`,
`llrt_crypto`, `llrt_fetch`, `llrt_fs`, `llrt_os`, `llrt_path`,
`llrt_stream_web` and `llrt_url`. All are version **0.10.0-beta** at
[LLRT commit 02833ca09748424a5960e37133530e24ccccae58][revision],
dated November 22, 2026. The pinned repository's [LICENSE] is Apache 2.0.
The workspace already uses anyhow, rquickjs, serde_json and Tokio.

The table includes transitive additions and new versions recorded in
Cargo.lock, including dependencies Cargo resolves for other platforms.
License expressions come from the pinned crate manifests.
