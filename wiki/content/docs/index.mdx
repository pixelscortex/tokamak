Tokamak is a Rust server with TypeScript plugins and a Solid 2 web client.
Tauri 2 supplies the desktop window. The client is rendered in the browser DOM.

| Directory           | Purpose                                                           |
| ------------------- | ----------------------------------------------------------------- |
| `packages/server/`  | Server and storage; builds `tokamak-server`                       |
| `packages/engine/`  | Server QuickJS engine, budgets and worker pool                    |
| `packages/runtime/` | Server facade, local server tools, reusable plugin lifecycle code |
| `packages/sdk/`     | Portable transport and plugin API, plus Solid 2 DOM entries       |
| `packages/build/`   | Server artifact compiler and static contribution analysis         |
| `packages/ui/`      | Placeholder for web primitives and tokens                         |
| `app/`              | Vite web app and Tauri host; `/kit` holds the controls page       |
| `wiki/`             | This docs site                                                    |

## Run

Install proto and rustup, then use the pinned tools in `.prototools`.
On macOS, install Xcode command-line tools. Other platforms need Tauri's native
build prerequisites.

```sh
proto run bun -- install --frozen-lockfile
```

Run `proto run bun -- run app` for the desktop client. It starts the Runner
and connects automatically. Install plugins from the separate
[tokamak-plugins repository](https://github.com/pixelscortex/tokamak-plugins);
use its `./install.sh --dev` for the development app. For browser development,
run `proto run bun -- run server:start` and `proto run bun -- run --cwd app dev`
in separate terminals, then open `http://127.0.0.1:1420`. The browser server helper
uses a disposable store and an empty plugins folder by default.

## Test and build

```sh
proto run bun -- run check
proto run bun -- run typecheck
proto run bun -- run test
proto run bun -- run e2e
proto run bun -- x playwright install --no-shell chromium webkit
proto run bun -- run e2e:browser
proto run bun -- run --cwd app build
proto run bun -- run --cwd app tauri build --no-sign
```

Ready pull requests run the Linux TypeScript and lint checks. Run the browser
suite locally; the Rust integration and desktop build workflows are manual.
On macOS arm64, `bash .ci/release-macos.sh` produces an unsigned app, zip and
standalone server archive in `.ci-results/macos-arm64`. The manual release
workflow uploads these artifacts without signing, notarization or publishing.
