Tokamak is a TypeScript-first application hosted by Rust. Reusable host,
runtime, renderer, SDK and UI packages live under `packages/`. The desktop
application is composed under `app/`, and `lab/` is a separate native
component catalog.

## What's in the repo

| Directory           | Purpose                                                            |
| ------------------- | ------------------------------------------------------------------ |
| `packages/server/`  | Native host crate; builds the `tokamak` executable                 |
| `packages/engine/`  | Shared QuickJS engine, budgets and worker pool                     |
| `packages/runtime/` | Feature-gated client and server hosts, and local process lifecycle |
| `packages/render/`  | Native UI renderer crate (Solid universal renderer on Blitz)       |
| `packages/sdk/`     | TypeScript feature API, `@tokamak/sdk`                             |
| `packages/ui/`      | TypeScript UI library, `@tokamak/ui`                               |
| `packages/build/`   | Private shared Vite, Solid and theme build integration             |
| `app/`              | Thin product shell, reserved for Core and plugins                  |
| `lab/`              | Independent native UI component catalog and interaction checks     |
| `wiki/`             | This docs site                                                     |

Cargo and Bun manifests and lockfiles stay at the repository root. Root
`plugins/` is reserved for future first-class plugins and is not scaffolded.

## Tools

`.prototools` pins moon, Bun and Rust; install [proto](https://moonrepo.dev/proto)
and rustup, and moon's toolchains read those pins. Bun is build tooling only:
it bundles, checks and tests TypeScript on your machine, and never runs in the
product.

```sh
bun install
```

## Run the app

```sh
bun run app            # debug build, start or reuse the server, launch the desktop
bun run ui:lab         # the native component catalog, no server or storage
```

The desktop connects to an independent local server. `bun run app` starts or
reuses it, and quitting the desktop does not stop it. Control it with:

```sh
bun run server:status
bun run server:stop
bun run server:start
```

`bun run build` makes the release server and desktop binaries.
`bun run plugin:build <folder>` builds one plugin artifact; see
[the build package](https://github.com/pixelscortex/tokamak/blob/dev/packages/build/README.md).

## Check and test

```sh
moon run :check :test :e2e
```

`:e2e` runs the five retired Todo scenarios on isolated fixture data and
depends on `app:test`. The repo's own runs set `CARGO_BUILD_JOBS=2`, which
limits Cargo to two parallel jobs. `moon run :size` measures the release binaries.

## The docs site

```sh
moon run wiki:dev      # landing page at /, docs at /docs
moon run wiki:build    # static site in wiki/dist/public
```
