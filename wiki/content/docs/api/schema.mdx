---
title: Schema
description: defineSchema and defineTable, which give handlers typed tables and documents.
---

A schema describes tables for types and host metadata. It is not enforced in
storage yet, and there are no migrations. Bind it with `createFunctions` to get
table, document and filter types in `ctx.db`.

```ts title="schema.ts"
import { defineSchema, defineTable, v } from "@tokamak/sdk";

export default defineSchema({
  todos: defineTable({ text: v.string(), done: v.boolean() }),
});
```
