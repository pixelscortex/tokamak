title: Client
description: TokamakClient and the in-process and WebSocket transports.
---

`TokamakClient` is a typed adapter over a transport, not a connection
manager. In-process and WebSocket transports share the same correlation and
subscription code, so application code is identical in both. Nothing retries
or reconnects: a closed stream can hide a committed mutation.

```ts
import { TokamakClient, WebSocketTransport } from "@tokamak/sdk";

const client = new TokamakClient(new WebSocketTransport(openSocket));
const id = await client.mutation(api.todos.add, { text: "Read this" });
const stop = client.subscribe(api.todos.list, { done: false }, (event) => {
  // event is { value } or { error }
});
stop();
```

## Transports

<api-declaration path="../../../../packages/sdk/src/client.ts" name="ClientTransport" />

`InProcessTransport` talks to a native host through an ordered message
connection; no port is opened. It bounds outstanding calls and subscriptions
at 128 each.
