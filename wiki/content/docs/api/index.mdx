title: SDK reference

---

`@tokamak/sdk` is the portable layer between TypeScript features and the native
host. Its `src/` uses ES2022 only, so the same code runs in QuickJS on the
server and in the UI. `@tokamak/sdk/solid` adds the optional Solid binding.

Each page below shows declarations and type tables read from
`packages/sdk/src` when the site builds, so they always match the code. The
build also fails if an export is missing from these pages.
