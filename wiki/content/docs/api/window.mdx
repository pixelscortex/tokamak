Import the window API from `@tokamak/sdk/client`. Export pages, components
and actions from your plugin's `src/client/api.tsx` so the build can discover them.

## Pages and components

`view` gives a page a literal route and can supply its title and icon.
The build publishes a typed `find` function for a plugin's JSX elements.
Names come from a static `data-part`, then a static `id`, then the component
or tag name. `data-part-ignore` excludes a subtree.

```tsx
import { view } from "@tokamak/sdk/client";

export const Composer = () => (
  <section>
    <button>Send</button>
  </section>
);

export const Work = view({ route: "/work", title: "Work" }, () => <Composer />);
```

## Actions on elements

Import another plugin's window entry through `plugin:example/client`.
An action targets a named element, such as `example.find("button", { in: "Composer" })`.
Use literal arguments. If a name matches several elements, narrow it with
`in` or use a 1-based `nth`.

| Action    | Effect                                                                            |
| --------- | --------------------------------------------------------------------------------- |
| `before`  | Add a sibling immediately before the element.                                     |
| `after`   | Add a sibling immediately after it.                                               |
| `prepend` | Add a child at the start.                                                         |
| `append`  | Add a child at the end.                                                           |
| `layer`   | Draw the original element, give it children, surround it, or draw something else. |
| `hide`    | Remove the element, its children, and additions before and after it.              |

Use `{ when: (props) => condition }` to make an action conditional. The
check is reactive and receives the declaring component's props, including
`$row.item` and `$row.index` inside a `For` row. The
`order` option sorts actions at the same position (default 0, then plugin ID).
Use `layer(target, (props, Original) => …)` to take over the element.
Render `<Original />` to draw the next layer down, or the owner's element
at the bottom. Pass children to change the contents without changing the
element or its attributes. Put `<Original.Children />` inside `<Original>` to
draw the contents that would appear without this layer: the children supplied
by an outer layer, or the owner's contents with other plugins' `prepend` and
`append`. Draw `Original` and `Original.Children` at most once per layer.
If no layer draws `Original`, the owner's element is unloaded. A layer with a
false `when` passes through.
Layers run outermost first by plugin install order, then `order` (default
0), plugin ID, and export name. `before` and `after` stay outside all layers;
`hide` also removes those sibling additions.

## Attach code to a component

`attach(example.find("Composer"), TrackComposer, { when })` runs
`TrackComposer` with the live props of each mounted `Composer` instance.
Use effects, cleanup and context as in a normal component. Returned JSX is
evaluated without drawing in place, so `Region.Panel` can still draw in the
shell's panel. Hiding or layering an element inside `Composer` leaves the
attachment running; removing the instance cleans it up.

`attach` searches named render functions, while placements search elements.
Use `in` to select an enclosing render function and `nth` for a 1-based
position. Attachments run in install order, then `order`, plugin ID and export
name. Missing targets after an owner update are skipped and reported. If an
attachment throws, it is stopped and a warning names its plugin and export.

## State

Read a value with `value()` and update it with `value.set(next)` or a
pure updater. `derived(() => value() * 2)` returns a read-only, reactive
computation. Both follow Solid's tracking rules.

| `keep`     | Where the value lasts                                   |
| ---------- | ------------------------------------------------------- |
| Omitted    | In the current window.                                  |
| `"device"` | On this device across window restarts.                  |
| `"me"`     | On the server for the signed-in member, across devices. |

Kept state needs the plugin build. Declare it at module scope with a stable
variable name so the build can give it a stable storage key.
