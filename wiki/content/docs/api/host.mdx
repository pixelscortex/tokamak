Plugin authors don't need this page. It is the contract between a backend
bundle and the native host. The bundle exports `schema`, `functions` (a
registry keyed by `module/path:export`), `metadata` and `invoke`. The host
owns call lifetime, read-only queries, transactions and change notifications.
