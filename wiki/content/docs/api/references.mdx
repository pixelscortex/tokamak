---

The build writes `_generated/api.ts` for each backend: typed references with
names and argument and result types, never handlers. A UI imports backend
modules only in type positions, so feature code never ships to the client.

```ts
import { api } from "./_generated/api";
const rows = await client.query(api.todos.list, { done: false });
```
