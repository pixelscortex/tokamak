A backend is a set of exported `query` and `mutation` definitions. Queries
get a read-only `ctx.db`, at the type level and at run time. Mutations can
also write, and everything one mutation writes commits together. Arguments are
validated before the handler runs.

```ts title="todos.ts"
import { createFunctions, v } from "@tokamak/sdk";
import schema from "./schema";
const { query, mutation } = createFunctions(schema);

export const list = query({
  args: { done: v.boolean() },
  handler: (ctx, { done }) => ctx.db.query("todos").where("done", "=", done).order("desc").collect(),
});
export const add = mutation({
  args: { text: v.string() },
  handler: (ctx, { text }) => ctx.db.insert("todos", { text, done: false }),
});
```

## Handler context

Queries, mutations and actions receive `ctx.auth.user`
(`id`, `name`, `role`) and `ctx.auth.device` (`id`, `name`) from the
signed-in connection. Subscriptions retain their caller,
and nested action calls and plugin-to-plugin calls preserve the original user.
Local mode supplies the owner `local`, named `You` (or `TOKAMAK_OWNER_NAME`).

## Choose where an action runs

Actions run beside the server by default. Set `on: "caller"` to run an action on the caller’s Runner, where it can use files and start programs with `ctx.proc`. Call it with `client.action` and handle `noMachine` if there is no Runner. Use `ctx.signal` to observe cancellation.
